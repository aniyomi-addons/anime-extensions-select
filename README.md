# anime-extensions-select

[![Aniyomi](https://img.shields.io/badge/Aniyomi-3D5AFE?logo=android&logoColor=fff&style=flat)](https://aniyomi.org)
[![Kotlin](https://img.shields.io/badge/Kotlin-7F52FF?logo=kotlin&logoColor=fff&style=flat)](https://kotlinlang.org)

A curated **extension repository** for **Aniyomi** and its forks (Anikku and others).
Add one link in the app to install the selected extensions and receive their updates automatically.

</div>

## 🎖️ Features

- **One link**: the app lists every extension of this repository as soon as it is added.
- **Automatic updates**: a new version published here shows up as an update in the app.
- **Signed builds**: every APK is signed with the same key, checked by the app against `repo.json`.

## 📋 Requirements

- Aniyomi, Anikku or another app that supports extension repositories.

## 📦 Installation

In the app, open **Settings → Browse → Extension repositories**, tap **Add**, and paste:

```
https://raw.githubusercontent.com/aniyomi-addons/anime-extensions-select/repo/index.min.json
```

Then open **Browse → Extensions** and install the extensions you want.
